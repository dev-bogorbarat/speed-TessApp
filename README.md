# Speed-T • Network & 3D Speed Test Suite

Aplikasi pengujian kecepatan internet interaktif dan visualisasi 3D futuristik yang dirancang dan dibangun oleh **Anak bangsa**.

## 🚀 Fitur Utama
- **Multi-Stream Speed Test**: Pengujian presisi untuk Download, Upload, Ping, dan Jitter dengan grafik real-time.
- **Visualisasi 3D Interaktif (Three.js)**: 6 mode objek 3D dinamis yang merespons latensi dan kecepatan koneksi (Quantum Orb, Cyber Core, Tron Tunnel, Neural Mesh, Hyper Portal, Matrix Wireframe).
- **Gaming Latency Matrix**: Pemantauan latensi server game populer (Valorant, MLBB, PUBG, Genshin Impact, Free Fire) beserta rekomendasi rute ISP.
- **AI Network Optimization Advisor**: Analisis diagnostik cerdas berbasis Google Gemini AI untuk memberikan saran praktis peningkatan stabilitas jaringan.
- **Sistem Lisensi Speed-T PRO VIP**:
  - Dukungan pembayaran QRIS / GoPay Rp 15.000 (A.N. Anak bangsa).
  - Portal Admin eksklusif untuk manajemen lisensi pembeli.
  - Generator Sertifikat Kecepatan resmi berstempel dan kartu snapshot media sosial.

## 🛠️ Menjalankan Proyek Secara Lokal

1. **Clone repository ini**:
   ```bash
   git clone <URL_REPOSITORY_ANDA>
   cd speed-t
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Jalankan dev server**:
   ```bash
   npm run dev
   ```
   Aplikasi akan berjalan pada `http://localhost:3000`.

4. **Build untuk Produksi**:
   ```bash
   npm run build
   npm start
   ```
